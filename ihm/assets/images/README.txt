Ce dossier devrait contenir les images suivantes pour le bon fonctionnement de l'application:

1. meter-sample.jpg - Image d'exemple d'un compteur électrique pour la démonstration
2. meter-sample-prev.jpg - Image d'exemple d'un compteur du mois précédent

Ces fichiers ne sont pas inclus dans le dépôt pour des raisons de taille, mais peuvent être remplacés par n'importe quelle image de compteur électrique pour des fins de test.

Pour un environnement de production, il faudrait mettre en place un système de stockage approprié pour les images téléversées par les utilisateurs.
